# ✦ Wendy's Star Library

> 把一颗颗 GitHub Stars，收进温柔的手账里。

### 🌸 [打开星星收藏馆 · Visit Star Library](https://wendyltan.github.io/star-library/)

一座可搜索、可分类、可发现新工具的 GitHub 收藏馆。这里有星星趋势、每周推荐和 42 枚可爱的原创手绘成就徽章。

**公开页面约每小时自动更新**（GitHub Actions 的定时任务可能延迟）。点击收藏书架的星星或推荐卡片上的「去 GitHub 收藏」，会在新标签页打开对应 GitHub 仓库；你可以直接在 GitHub 官方页面点击 Star 或取消 Star。收藏馆本身不会请求额外 GitHub 授权，也不会自动修改任何 Stars。

这个仓库仅用于托管经过隐私过滤的静态展示页面；自动化源码、访问令牌、Gist 原始数据及内部复核资料都不在此仓库。
